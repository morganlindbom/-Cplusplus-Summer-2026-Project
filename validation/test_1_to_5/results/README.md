# Pins 1-5 results

This directory is reserved for future machine-readable certification results. It is intentionally empty while the canonical protocol is being defined.

Results must be produced by the GUI certification runner through the real PVD workflow. Do not hand-edit a result into `PASS`. Transfer, Runtime, and Debug must remain `NOT-TESTED`/`NOT-RUN` until the current hardware policy permits those stages and they are actually verified.
